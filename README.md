# Xenios KB Bot

AI-powered WordPress chatbot driven entirely by your own knowledge base. Bring
your own AI provider API key — no bundled subscription, no external hosting
dependency for your knowledge base data.

See `readme.txt` for the full WordPress.org plugin description, installation
steps, and FAQ.
